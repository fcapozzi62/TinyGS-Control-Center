# Changelog

## 0.0.1 — 2026-11-01

- Initial independent community repository structure.
- Python standard-library OMM JSON importer with support for six-digit NORAD IDs.
- SQLite catalog with append-only orbital element history and provenance.
- CLI for local import, CelesTrak fetch and catalog inspection.
- Offline unit tests, GitHub Actions and design documentation.
- No MQTT control, orbital propagation or scheduler yet.
